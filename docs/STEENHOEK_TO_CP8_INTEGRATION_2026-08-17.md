# Steenhoek → CP8 Integration — 2026-08-17

Status: experimental extraction, not promotion of external claims

## Purpose

Extract reusable structural ideas from David Steenhoek's public work into falsifiable CP8 modules. Established physics, analogy, and speculation remain explicitly separated.

## Module T1 — Topological invariants

Goal: compare structures by deformation-resistant relations rather than visual resemblance alone.

Minimum outputs:
- connected components
- cycle rank
- winding/path signature where defined
- persistent/deformation signature
- pass/fail under rotation, scale, affine distortion and redraw controls

Promotion condition: topology must remain stable under allowed transformations and separate matched controls.

## Module T2 — Dynamic Fibonacci driver

Goal: test Fibonacci as an ordering process rather than merely searching for phi ratios.

Compare matched drivers:
- periodic
- randomized
- Fibonacci word substitution
- alternative substitution sequence

Measure whether output morphology, stability, coherence, or topology differs reproducibly. No special status is assigned to Fibonacci without matched controls.

## Module T3 — Process genome

Goal: distinguish final state from generative history.

Record an ordered operation sequence independently of final geometry. Two equal-looking outputs with different process genomes are not treated as equivalent by default.

## Module T4 — Resonance morphology

Goal: map driven physical or simulated systems to spatial geometry.

Required variables:
- driver family and sequence
- frequency/time schedule where applicable
- boundary conditions
- medium/model
- generated spatial structure
- matched control

A resemblance claim is insufficient; the same driver must reproducibly generate the same measured signature.

## Module T5 — Observer context

Every receipt records instrument/model, coordinate frame, resolution, transforms and preprocessing. Representation is never silently equated with the underlying object.

## Module T6 — Emergence analysis

Goal: test whether global structure contains measurable organization not reducible to trivial local statistics.

Candidate comparisons:
- local feature baseline
- shuffled adjacency control
- degree-preserving graph randomization
- motif distribution
- global topology
- compression/description-length delta

## Module T7 — Lattice classifier

Candidate classes include square, triangular, hexagonal, radial, quasicrystalline, substitution-based, aperiodic and unclassified.

Classification must expose confidence and symmetry evidence. Labels below the configured confidence gate remain experimental.

## Module T8 — Analogy firewall

Cross-domain language is classified as one of:
- OBSERVED
- MEASURED
- MATHEMATICAL_CORRESPONDENCE
- PHYSICAL_MECHANISM
- ANALOGY
- HYPOTHESIS
- SPECULATION

Rules:
1. Analogy is not mechanism.
2. Shared vocabulary is not mathematical correspondence.
3. Mathematical correspondence requires an explicit mapping and discriminating prediction.
4. Physical mechanism requires mapping, prediction, and mechanism-specific evidence.
5. ANALOGY, HYPOTHESIS and SPECULATION cannot be promoted above EXPERIMENTAL by the component gate.
